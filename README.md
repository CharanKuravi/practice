# NPTEL AI Exam Prep Quiz

Plain static site: one file (`index.html`), no build step, no dependencies.

## Deploy on Vercel
1. Push this folder to GitHub, then Import Project in Vercel.
2. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy.
(Or: `npm i -g vercel` then run `vercel` inside this folder.)

## Deploy on Netlify
Drag and drop this folder at app.netlify.com/drop.

## Run locally
Just open index.html in a browser.
